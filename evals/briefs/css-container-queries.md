# Brief — Container queries instead of media queries for components

Slug: css-container-queries
Source: `brief.source.md` (the brief as it was supplied, kept unchanged)

## Reader (BRF-1)
- **Who:** a front-end developer who maintains a component library
- **Already knows:** media queries and flexbox layout
- **Needs to decide or do:** decide whether to rewrite responsive components with container queries

## Goal and call to action (BRF-2)
- **Goal:** the reader can write a container query for one component and knows the browser support picture
- **CTA:** open the example component at https://example.com/container-demo
