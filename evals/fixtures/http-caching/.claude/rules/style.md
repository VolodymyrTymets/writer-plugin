# Style guide — Example Engineering Blog

Filled in for one client or publication. The plugin's generic rules never contain these values.

## Audience
- **Readers:** backend developers at small software companies who run their own servers

## Voice (VOI-1)
- **Tone:** plain, direct
- **Person:** second person
- **Do:** short sentences, concrete examples
- **Do not:** hype, rhetorical questions

## Banned phrases (VOI-2)
- **Phrases:** game changer, in today's world

## AI tells to flag (VOI-3)
- **Tells:** delve into, it is worth noting

## Reading level (VOI-4)
- **Target:** Flesch-Kincaid grade 10 or lower

## Facts (FACT-4)
- **Statistic age limit (months):** 120

## Links (SEO-5)
- **Internal links:**
  - Example caching config → https://example.com/caching-config
- **Preferred external publishers:** IETF, MDN
